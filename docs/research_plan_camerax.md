# CameraX API Araştırma Planı

## Görev Özeti
Android CameraX API'nın güncel kullanımı, kamera önizlemesi kurulumu, frame yakalama ve işleme teknikleri hakkında kapsamlı araştırma. Kotlin kod örnekleri ile birlikte detaylı dokümantasyon hazırlanması.

## Araştırma Konuları
1. CameraX API güncel durum ve versiyonları (2024-2025)
2. Kamera önizlemesi (Preview) kurulumu
3. Frame yakalama ve işleme teknikleri
4. Use Case'ler: ImageAnalysis, Preview, ImageCapture
5. Lifecycle yönetimi
6. OpenCV ile entegrasyon
7. Kotlin kod örnekleri ve best practices
